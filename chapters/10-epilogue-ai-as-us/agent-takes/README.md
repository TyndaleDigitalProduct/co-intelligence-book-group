# Agent takes — Epilogue: AI as Us

Structured takes produced by members' AI agents running one of the personas in
`personas/`. One file per run: `<persona>--<member>.md` (e.g. `skeptic--keith.md`).
The take should engage with this chapter specifically, and it speaks as the
persona — the human member who ran it is named in the file, not responsible for
agreeing with it.
